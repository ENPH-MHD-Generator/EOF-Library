# MHD solvers for seeded-argon plasmas

Two solvers model the current, Joule heating and Lorentz force in a
compressible, potassium-seeded argon flow through a linear Hall channel:

- **MHDSolve** (`libs/solvers/MHDSolve/`), an Elmer solver adapted from
  StatCurrentSolve. At every node it computes the plasma state and the
  conductivity tensor and solves for the electric potential and current.
- **mhdLinearHall** (`solvers/mhdLinearHall/`), an OpenFOAM solver for
  compressible laminar flow (rhoPimpleFoam-like) with the `J x B` force in the
  momentum equation and `J.E` in the energy equation.

`tests/linearHall/` is a complete prepared example that runs both, coupled
through EOF-Library.

## Physics in MHDSolve

- **Ionization.** Only the seed ionizes. The Saha equation is solved at the
  electron temperature `Te`, with heavy-particle densities from the gas
  temperature and pressure.
- **Electron transport.** Electron-neutral collisions come from tables
  (below); electron-ion collisions use the NRL frequency and Coulomb logarithm
  at the local `n_e` and `Te`. `drifting` adds the collision frequencies, a lower
  bound on the conductivity. `lorentz` adds them inside the velocity average,
  using mobilities tabulated against `Te`, `n_e ln(Lambda)/N` and
  `omega_ce/N`, an upper bound.
- **Ion slip.** Ions carry current with mobility `Ion Reduced Mobility x N0/N`.
- **Conductivity tensor.** `J = sigma_0 (b.E') b + sigma_P E'_perp + sigma_H b x E'`
  from electrons and ions, with the parallel value clamped to
  `[Sigma Min, Sigma Max]`.
- **Electron temperature.** With `Two Temperature`, `Te` follows from electron
  Joule heating against elastic recoil and the K 4s-4p inelastic loss. It is
  either a local balance or, with `Electron Energy Transport`, a transported
  electron energy equation with sheath losses at walls
  (`Electron Wall Heat Transmission`).
- **Electrodes.** Pairs of electrode boundaries (`Electrode Pair`,
  `Electrode Sign`, `Electrode Resistance`) are connected through external
  loads by Lagrange multipliers.

The Material keywords are listed with comments in `tests/linearHall/case.sif`
(`Material 1`).

## Electron collision data

`Electron Collision Data` names a text file that MHDSolve reads once:

- `!` lines are comments.
- Blocks are `<name> <count>` followed by `count` values, ending with `end 0`.
  The first block is `format 1`.
- `theta` is the electron temperature grid in eV.
- On that grid, per heavy-particle density: `momentum_frequency_n`,
  `elastic_recoil_n`, `ei_recoil_per_coulomb`, `k_excitation_K`,
  `k_superelastic_K`.
- Scalars: `excitation_energy_K`, `excitation_weight_ratio_K`.
- For `lorentz` only: grids `coulomb_parameter` and `magnetic_parameter`, and
  the cubes `mobility_n`, `pedersen_mobility_n`, `hall_mobility_n` in Fortran
  order, `theta` fastest.

Unknown blocks are ignored. Values are interpolated log-log and held at the
grid ends. The example's file was generated by
[plasma_collisions](https://github.com/ENPH-MHD-Generator/plasma_collisions) for
a Maxwellian electron distribution; its provenance is in
`electron_collisions.json`.

## Coupling

OpenFOAM sends `Ux Uy Uz Bx By Bz p T` and receives `Jx Jy Jz JH potential
elcond_elmer ionizationFraction Te hallParameter pedersenConductivity`.
Electrical fields are transferred per Elmer element (`Variable_on_elements` in
`Elmer2OpenFOAM`). mhdLinearHall re-solves Elmer only when U, T or p change by
more than the tolerances in `constant/couplingProperties`, or after
`maxStepsBetweenUpdates` steps.

## Build and run the example

The solver image builds OpenFOAM 6, Elmer 8.4 with MUMPS and Hypre (gcc 9), the
EOF coupler, mhdLinearHall and MHDSolve (`docker/Dockerfile`, recipes in
`docker/mk/`):

```sh
make solver-image
docker run --rm -it --platform linux/amd64 \
  -e HOST_USER_ID=$(id -u) -e HOST_USER_GID=$(id -g) \
  -v $PWD/tests/linearHall:/home/openfoam/linearHall eof-mhd-solvers:latest
cd ~/linearHall && ./Allrun     # converts and partitions the mesh, then runs on 2+2 ranks
./Allclean                      # back to the committed state
```

To run it without an interactive shell, pass the command to the entrypoint with
`-c`, as in `docker run ... eof-mhd-solvers:latest -c "cd ~/linearHall && ./Allrun"`.
It takes about a minute and finishes at `endTime` 1e-4 s, with VTK output in
`tests/linearHall/VTK`.
